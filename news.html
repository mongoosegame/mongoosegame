Awseome Mongoose Game v1.1 release!

Posted on: 01/04/2026

This version adds many QOL changes and bug fixes alongside some graphical improvements and a new level.

Full list

  • Fixed bug: The player no longer slides when sudden movements are made
  • Change: Slightly changed level 2's layout to accommodate for the level 3 entrance
  • Change: Updated Level 1 visuals
  • New: Added a speedrun timer setting
  • New: Added a way to select the level you play
  • New: Added a 3rd optional level
  • New: Added a way to reset to main menu by holding R down
  • New: Added a win screen
  • Removed: Game closing on win
