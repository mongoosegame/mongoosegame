What is the Awseome Mongoose Game?

The Awseome Mongoose Game is a simple 2D platformer game developed by ProfWhizz, initially for a 20 minute game-dev challenge.

Where can I play it?

You can play The Awseome Mongoose Game on Itch.io or the official Awseome Mongoose Game website
