About

What is the Awesome Mongoose Game?

The Awesome Mongoose Game is a simple 2D platformer game developed by ProfWhizz, initially for a 20 minute game-dev challenge.

Where can I play it?

You can play and download The Awesome Mongoose Game on Itch.io or the official Awesome Mongoose Game website.

Where can I recieve Awesome Mongoose Game news & updates?

You can get news on the Awesome Mongoose Game on The Awesome Mongoose Game website, The Awesome Mongoose Game Twitter, The Awesome Mongoose Game YouTube Channel, or the Tuff Grigma Gaming YouTube Channel (no longer used for the game)

Tuff Grigma Gaming

How many levels does the Awesome Mongoose Game have?

The Awesome Mongoose Game currently has 2 main levels along with 1 bonus level!

What platforms can I play the Awesome Mongoose Game on?

You can play the Awesome Mongoose Game on Windows, Linux, and Android! Minimum and recommended specs will be coming soon!

Does the Awesome Mongoose Game have controller support?

Yes! The Awesome Mongoose Game has controller support, however you will need to use a mouse to click on the buttons at the end of the levels.
